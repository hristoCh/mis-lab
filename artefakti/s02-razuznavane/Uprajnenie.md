# Упражнение s02: разузнаване

Цел: Server (192.168.56.3), сканиран от Gateway с nmap и ffuf.

## Открити услуги
- 22/tcp: OpenSSH 10.0p2 Debian
- 80/tcp: Apache httpd 2.4.68 (Debian)
- 8080/tcp: Apache httpd 2.4.49 (Unix), vulhub CVE-2021-41773

## Риск 1: Apache 2.4.49 (CVE-2021-41773)
- CVSS 3.1: 9.8 по NVD, 7.5 по cve.org и Red Hat.
- Path traversal, достъпен по мрежата без автентикация, с ниска сложност.
- Контейнерът е с включен CGI модул, а при включен CGI уязвимостта може да доведе до изпълнение на код.
- Включена е в каталога на CISA за активно експлоатирани уязвимости.
- ffuf откри /cgi-bin/ (403), което потвърждава наличието на CGI.
- Мярка: обновяване до версия след 2.4.50 (поправката във 2.4.50 е непълна, CVE-2021-42013), изключване на CGI и ограничаване на достъпа до порта.

## Риск 2: SSH с вход с парола и слаба парола
- Порт 22 приема вход с парола, а паролата на потребителя student е кратка и лесна за налучкване.
- Успешен вход дава интерактивен достъп до сървъра.
- Мярка: вход само с SSH ключове (PasswordAuthentication no), дълга парола, ограничаване на достъпа по IP.
- Забележка: в лабораторията слабата парола е приета умишлено, на реална система не е допустима.

## Използвани техники (MITRE ATT&CK)
- Active Scanning (Reconnaissance)
- Network Service Discovery (Discovery)
- Exploit Public-Facing Application (Initial Access), само като оценка на риска, без експлоатация
